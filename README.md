## 1. Project Overview

This project focuses on predicting house prices using machine learning regression models and comparing their performance based on three evaluation metrics: Mean Absolute Error (MAE), Mean Squared Error (MSE), and the coefficient of determination (R²).

## 2. Objective

The main objective of this project is to develop an end-to-end machine learning pipeline for house price prediction and compare the performance of different regression models.

The following models are evaluated:

- Linear Regression
- Random Forest Regressor
- XGBoost Regressor

## 3. Conclusion

This project developed an end-to-end machine learning pipeline for house price prediction using the Seattle housing dataset. Three regression models were trained and evaluated: Linear Regression, Random Forest, and XGBoost.

The results showed that XGBoost achieved the lowest MAE, while Linear Regression achieved the highest R² and the lowest MSE. Random Forest showed poor performance on the test set, with a negative R² score.

Overall, the project demonstrates the complete workflow of data validation, data cleaning, exploratory data analysis, preprocessing, model training, evaluation, and model comparison.

The machine learning approaches used in this project can also be adapted to urban resilience and emergency management applications.
